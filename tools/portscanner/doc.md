# Portscanner

Вы можете доработать сканер под собственные нужды и скомпилировать новый бинарник. Для этого следуйте инструкции:

1. Установить Go 1.21 или выше
```bash
sudo apt update
sudo apt install golang-go
```

Проверьте:
```
go version
```

Если пакетная версия Ubuntu слишком старая, можно установить официальный архив с сайта Go.

2. Перейдите в каталог модуля

3. Измените код

4. Отформатируйте
```bash
gofmt -w main.go
```

5. Проверьте форматирование
```bash
gofmt -d main.go
```

6. Проверьте модуль и соберите бинарник
```bash
go mod tidy
go vet ./...
go build -o portscanner .
```
